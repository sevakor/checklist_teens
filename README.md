# Чекліст: чи готовий/а я до сексу?

Mobile-first React-застосунок для приватної саморефлексії перед рішенням про сексуальну близькість.

## Приватність

- Вибрані твердження і поточний крок зберігаються тільки в `sessionStorage`.
- Після 15 хвилин у фоновій вкладці або після завершення чекліста відповіді видаляються.
- У `localStorage` зберігається тільки факт завершення, щоб під час наступного візиту відкрити матеріали.
- Відповіді не додаються до URL і не надсилаються мережею.

## Розробка

```sh
pnpm install
pnpm dev
```

Перевірки запускаються командами `pnpm lint`, `pnpm typecheck`, `pnpm test` і `pnpm build`.

Каталог та маршрути чотирьох додаткових матеріалів уже закладено. Їхні текстові блоки, спойлери й наявні інтерактиви оформлюються на наступному етапі.
